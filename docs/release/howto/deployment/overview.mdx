Hosted catalog: [Cloud](/howto/deployment/cloud). This page is what you run on this machine.

| Habit | What you run | What starts |
|-------|----------------|-------------|
| No HTTP | `pxt schema update`, insert, `export_sql`, exit | Nothing listening |
| Your FastAPI | Same apply, then `app.include_router(api)` | Your process. [HTTP serving](/howto/deployment/serving) |
| `pxt service` | Same apply, then `pxt service update` | A process Pixeltable starts. [Quickstart](/overview/quick-start) |

`uvx pixeltable-new myapp` copies the chat agent (TARGET `agent`). `--video` copies video search (TARGET `videointel`).

## No HTTP

Insert, let computed columns run, export, exit. Same snippet: [chat-agent README](https://github.com/pixeltable/pixeltable-starter-kit/blob/main/chat-agent/README.md).

```bash
pxt schema update app.py agent
```

```python
from pixeltable.io.sql import export_sql

from app import Knowledge

Knowledge.insert(
    [{'body': 'One application file. Insert runs compute.', 'title': 'intro', 'source': 'docs'}]
)
export_sql(
    Knowledge.select(Knowledge.title, Knowledge.body, Knowledge.uuid),
    'knowledge',
    db_connect_str='sqlite:///agent.db',
    if_exists='replace',
)
```

Persistent volume, Dockerfile: [Infrastructure](/howto/deployment/infrastructure) and [Operations](/howto/deployment/operations).
