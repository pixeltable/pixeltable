Hosted catalog: [Cloud](/howto/deployment/cloud). This page is which local process to start after `pxt schema update`.

| If you want | What you run | What starts |
|-------|----------------|-------------|
| Python only | `pxt schema update`, insert from Python, then `export_sql` | Nothing listening |
| Your FastAPI | `pxt schema update`, then `app.include_router(...)` | Your process. [HTTP serving](/howto/deployment/serving) |
| `pxt service` | `pxt schema update`, then `pxt service update` | A process Pixeltable starts. [Quickstart](/overview/quick-start) |

`uvx pixeltable-new myapp` copies the chat agent; pass `agent` as the last argument to `pxt schema update`. `--video` copies video search; pass `videointel`.

## Python only

This example expects the starter-kit chat agent (`Knowledge` in that repo's `app.py`). Insert rows, then export them to SQLite. Same snippet: [chat-agent README](https://github.com/pixeltable/pixeltable-starter-kit/blob/main/chat-agent/README.md).

```bash
pxt schema update app.py agent
```

```python
from pixeltable.io.sql import export_sql

from app import Knowledge

Knowledge.insert(
    [{'body': 'One application file. Insert runs compute.', 'title': 'intro', 'source': 'docs'}]
)
export_sql(
    Knowledge.select(Knowledge.title, Knowledge.body, Knowledge.uuid),
    'knowledge',
    db_connect_str='sqlite:///agent.db',
    if_exists='replace',
)
```

For Docker and disks, see [Infrastructure](/howto/deployment/infrastructure) and [Operations](/howto/deployment/operations).
