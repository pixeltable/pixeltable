Hosted databases are backed up by Pixeltable Cloud. Local catalog: dump `pgdata` and copy media.

| Habit | Backup | Restore |
|-------|--------|---------|
| No HTTP | Your RDBMS and blob store. `app.py` in git. | Re-apply, then re-insert |
| Long-running service | `pg_dump` of `~/.pixeltable/pgdata` plus `~/.pixeltable/media/` (or bucket versioning) | Restore `pgdata` and media, restart |

```bash
pg_dump -h ~/.pixeltable/pgdata -U postgres pixeltable > backup.sql
tar -czf media_backup.tar.gz ~/.pixeltable/media/
```

Restore: stop the process, `psql -f backup.sql`, restore media, start.

Pixeltable does not manage end-user accounts. Put auth on your HTTP layer. Do not expose PostgreSQL port 5432. Prefer IAM / Workload Identity over keys in `config.toml`.

```python
import os

OPENAI_API_KEY = os.getenv('OPENAI_API_KEY')
```

Hosted secrets: `pxt secret set`. [Cloud](/howto/deployment/cloud). Table history: [Version control](/platform/version-control).
