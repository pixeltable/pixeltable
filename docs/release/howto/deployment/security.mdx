title: 'Security and backup'
description: 'pg_dump the catalog, restore, keep secrets out of app.py.'
---

Hosted databases are backed up by Pixeltable Cloud. For a local database, back up `~/.pixeltable/pgdata` and `~/.pixeltable/media`.

| Setup | Backup | Restore |
|-------|--------|---------|
| No HTTP | If you exported with `export_sql`, keep that SQL copy and `app.py` in git | Run `pxt schema update` again, then insert the data again |
| Long-running service | `pg_dump` of `~/.pixeltable/pgdata` plus `~/.pixeltable/media/` (or bucket versioning) | Restore `pgdata` and media, restart |

```bash
pg_dump -h ~/.pixeltable/pgdata -U postgres pixeltable > backup.sql
tar -czf media_backup.tar.gz ~/.pixeltable/media/
```

Stop Pixeltable, restore Postgres from the dump, copy `media` back, then start Pixeltable again.

Pixeltable does not manage end-user accounts. Put auth on your HTTP layer. Do not expose PostgreSQL port 5432. Do not put long-lived cloud keys in `config.toml` if the host can use its own IAM role.

```python
import os

OPENAI_API_KEY = os.getenv('OPENAI_API_KEY')
```

On Cloud, store secrets with `pxt secret set` ([CLI](/platform/cli#pxt-secret)). Table history: [Version control](/platform/version-control).
