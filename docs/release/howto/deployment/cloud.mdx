Create a hosted database. Apply the same [Quickstart](/overview/quick-start) file to a `pxt://` URI.

<Tip>
`PIXELTABLE_API_KEY` is required. Set it in the environment or in `config.toml`. See [Configuration](/platform/configuration).
</Tip>

```bash
pxt db create pxt://org:mydb
pxt db update pxt://org:mydb
pxt schema update app.py pxt://org:mydb
pxt service update app.py pxt://org:mydb
```

Then `t = pxt.get_table('pxt://org:mydb/docs')`.

`pxt db update` reconciles the hosted database with the project's `[[pixeltable.database]]` entry: secrets first, then the image and the project archive, then capacity. `pxt schema update` creates the tables. It does not start HTTP. `pxt service update` starts HTTP on that catalog. `pxt service run` stays on this machine.

If `pxt service diff` says the database project is behind the working copy, run `pxt db update` first.

## Secrets

`pxt secret set` still works:

```bash
pxt secret set pxt://org OPENAI_API_KEY=sk-...
```

A project can declare the same secrets on the database entry as the name of an environment variable, never the value. `pxt db update` sets them from there:

```toml
[[pixeltable.database]]
name = 'pxt://org:mydb'

[pixeltable.database.secrets]
openai_api_key = 'env:OPENAI_API_KEY'
```

A running database keeps the values it started with. Run `pxt db stop` then `pxt db start` to pick up a change.

## Image and archive {#hosted-catalog}

The project ships as two artifacts:

| Artifact | Holds | Moves when |
|---|---|---|
| Image | Python environment, no project code | lockfile, `python_version`, `system_dependencies`, or the Pixeltable version |
| Project archive | Selected project files | any selected file |

A source edit ships the archive. A lockfile edit rebuilds the image as well. `pxt db diff pxt://org:mydb` shows which. `pxt db update` applies it. `pxt db build-image pxt://org:mydb` does both unconditionally.

Built-ins and provider functions in `app.py` apply on Cloud. A `@pxt.udf` or custom iterator defined only in a local file does not. Put it in the project `pxt db update` packs.

Flags: [CLI](/platform/cli#cloud).

## Media on the home bucket

Every Cloud database includes a managed bucket. No provider account, no credentials file. Declare it on a computed column:

```python
class Images(TableModel, name='images'):
    photo: pxt.Image
    thumbnail = pxt.Column(
        value=photo.resize((256, 256)),
        destination='pxtfs://org:mydb/home',
    )
```

Or set `output_media_dest` as the default for computed media. Details: [Cloud storage](/integrations/cloud-storage).

## Local vs Cloud

| | Local | Cloud |
|---|---|---|
| Catalog | `pxt schema update app.py my_app` | `pxt schema update app.py pxt://org:mydb` |
| HTTP | `pxt service update app.py my_app` | `pxt service update app.py pxt://org:mydb` |
| Media | local disk | `pxtfs://org:mydb/home` |

`pxt db` also lists, starts, stops, and deletes hosted databases. [CLI](/platform/cli#cloud).
