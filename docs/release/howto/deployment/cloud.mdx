The [Quickstart](/overview/quick-start) file is the Cloud file. Pack the hosted database, declare the tables, then serve.

`PIXELTABLE_API_KEY` is required. Set it in the environment or in `config.toml`. [Configuration](/platform/configuration).

`pxt init` writes `pixeltable.toml`. Name the hosted database in that file, then pack, declare, and serve:

```toml
[[pixeltable.database]]
name = 'pxt://org:mydb'
```

```bash
pxt db update pxt://org:mydb
pxt schema update app.py pxt://org:mydb
pxt service update app.py pxt://org:mydb
```

Then `t = pxt.get_table('pxt://org:mydb/docs')`.

```python
import pixeltable as pxt
import pixeltable.functions as pxtf
from pixeltable.serving import FastAPIRouter

TableModel = pxt.model_base()


class Docs(TableModel, name='docs'):
    title: pxt.String
    body: pxt.String | None
    title_upper = pxtf.string.upper(title)


ingest = FastAPIRouter(name='ingest')
ingest.add_insert_route(
    Docs, path='/docs', inputs=[Docs.title, Docs.body], outputs=[Docs.title, Docs.title_upper]
)
```

`pxt db update` creates the hosted database or brings it up to what the project declares: image, secrets, capacity. That is Pack. It is not Experiment. `pxt schema update` creates the tables. It does not start HTTP. `pxt service update` starts hosted HTTP. `pxt service run` is local only.

Experiment on Cloud: insert from the dashboard, then `pxt schema diff`.

## Media on the home bucket

Every Cloud database includes a managed bucket. No provider account, no credentials file. Declare it on a computed column:

```python
class Images(TableModel, name='images'):
    photo: pxt.Image
    thumbnail = pxt.Column(
        value=photo.resize((256, 256)),
        destination='pxtfs://org:mydb/home',
    )
```

Or set `output_media_dest` as the default for computed media. Details: [Cloud storage](/integrations/cloud-storage#pixeltable-cloud-home-bucket).

## Local vs Cloud

| | Local | Cloud |
|---|---|---|
| Pack | (this machine) | `pxt db update pxt://org:mydb` |
| Catalog | `pxt schema update app.py my_app` | `pxt schema update app.py pxt://org:mydb` |
| HTTP | `pxt service update app.py my_app` | `pxt service update app.py pxt://org:mydb` |
| Experiment | insert, `pxt dashboard`, `pxt schema diff` | dashboard insert, `pxt schema diff` |
| Media | local disk | `pxtfs://org:mydb/home` |

`pxt db` also lists, starts, stops, diffs, and deletes hosted databases. `pxt db build-image` rebuilds the Python image without waiting for drift. [CLI](/platform/cli#cloud).
