The playbook is for agents with terminal access. Humans: [Quickstart](/overview/quick-start).

Do not copy this repo's `AGENTS.md` into an application. That file is for Pixeltable contributors.

Example prompts: add a computed column on `Articles`; `pxt schema update app.py my_app`; add an insert route.

## MCP

Two servers. Per-editor config is in the [playbook](https://www.pixeltable.com/get-started.md). There is no hosted authenticated control-plane MCP.

| Server | Transport | Use |
|--------|-----------|-----|
| `pixeltable-web` | HTTP | Read-only docs search. Endpoint: `https://pixeltable.com/mcp` |
| `pixeltable-developer` | stdio | Inspect and query a local or Cloud catalog |

WebMCP does not mutate tables. Catalog changes go through the developer server (keep human confirmation on) or the CLI: `pxt ls --json`, `pxt describe --json`, `pxt errors`.

To call remote MCP tools from a table, `pxt.mcp_udfs(url)`. [Agents as tables](/use-cases/agentic-workflows).
