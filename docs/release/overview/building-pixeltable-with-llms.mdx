Hand the agent [get-started.md](https://www.pixeltable.com/get-started.md) to install the CLI, the [skill](https://github.com/pixeltable/pixeltable-skill), and MCP. After that, follow the [Quickstart](/overview/quick-start): generate an example app, create its tables, then start the endpoints.

The skill tells the coding agent not to use LangChain, pandas as a database, per-row model loops, or a separate vector database. An application is a Python file that declares tables as `TableModel` classes. Notebooks can still use `pxt.create_table()`.

## Set Up Your AI Tool

```bash
npx skills add pixeltable/pixeltable-skill
```

Works with tools that support [Agent Skills](https://agentskills.io/specification): Cursor, Claude Code, Windsurf, Cline, OpenCode, Codex CLI, and others.

## What the agent should write

Write an application file, then create its tables with `pxt schema update app.py my_app`. When you insert a row, computed columns run automatically.

```python
import pixeltable as pxt
import pixeltable.functions as pxtf

TableModel = pxt.model_base()


class Articles(TableModel, name='articles'):
    title: pxt.String
    body: pxt.String
    response = pxtf.openai.chat_completions(
        messages=[{'role': 'user', 'content': body}],
        model='gpt-4o-mini',
    )
    summary = response.choices[0].message.content
```

```bash
pxt schema update app.py my_app
```

After the schema exists, open the table with `t = pxt.get_table('my_app.articles')` and insert rows, or serve the same file over [HTTP](/howto/deployment/serving). To run that file on Pixeltable Cloud, sign in with `pxt login` and run `pxt db update`, then `pxt schema update`, then `pxt service update`, against `pxt://org:main`: [Pixeltable Cloud](/cloud).

## Choose a Pixeltable MCP server

The [Pixeltable plugin](https://github.com/pixeltable/pixeltable-skill) packages the Skill for Claude, Cursor, and ChatGPT. Neither the plugin nor the Skill configures an MCP server; add the one the job needs.

| Server | Connect to | Access |
|---|---|---|
| [Docs MCP](https://docs.pixeltable.com/mcp) | `https://docs.pixeltable.com/mcp` | Public documentation search. The page menu can install it in Cursor or VS Code. |
| [Site MCP](https://www.pixeltable.com/mcp) | `https://www.pixeltable.com/mcp` (remote HTTP) | Public documentation search and integration listing. This URL accepts MCP JSON-RPC requests; the site's in-browser WebMCP tools are separate. |
| [Cloud MCP](https://pixeltable.com/developers/mcp-cloud) | `https://www.pixeltable.com/mcp/cloud` | The Cloud organization selected during WorkOS AuthKit sign-in. Reads databases, services, catalog entries, schemas, up to 25 table rows per call, and logs. Starts a database at once. Stops a database, restarts a service, or sets a secret only when called again with `confirm: true` after returning a preview. Add `?read_only=true` for the read tools only, or `?db=<name>` for one database. Connect it as a remote HTTP server in Claude Code, Cursor, or another MCP client. |
| [Developer MCP](https://github.com/pixeltable/mcp-server-pixeltable-developer) | Local stdio command | Catalog inspection, queries, and REPL tools against a local or Cloud database. Install and run it on your machine; it has broader capabilities than the hosted Cloud MCP. |

To deploy or delete, use the `pxt` CLI after `pxt login`: `pxt db update` and `pxt service update` ship code, and the hosted Cloud MCP does neither.

Catalog inspection without importing Python: `pxt ls --json`, `pxt describe --json`, `pxt errors`. The `pxt` CLI (v0.7.4+) exposes `--json` on inspection and query commands. See the [CLI](/platform/cli).

To call remote MCP tools from a table column, use `pxt.mcp_udfs(url)` (see [Agents as tables](/use-cases/agentic-workflows)).
