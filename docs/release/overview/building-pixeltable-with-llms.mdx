Install the [Pixeltable Agent Skill](https://github.com/pixeltable/pixeltable-skill). Then the loop is the [Quickstart](/overview/quick-start): `pxt service example` → `pxt schema update` → `pxt service update`.

The skill steers the model off LangChain, pandas-as-store, per-row model loops, and a separate vector DB. Apps are a `TableModel` file. Notebooks can still use `pxt.create_table()`.

## Set Up Your AI Tool

```bash
npx skills add pixeltable/pixeltable-skill
```

Works with tools that support [Agent Skills](https://agentskills.io/specification): Cursor, Claude Code, Windsurf, Cline, OpenCode, Codex CLI, and others.

## What the agent should write

An application file, then `pxt schema update app.py my_app`. Inserts compute on the way in.

```python
from __future__ import annotations

import pixeltable as pxt
import pixeltable.functions as pxtf

TableModel = pxt.model_base()


class Articles(TableModel, name='articles'):
    title: pxt.String
    body: pxt.String
    response = pxtf.openai.chat_completions(
        messages=[{'role': 'user', 'content': body}],
        model='gpt-4o-mini',
    )
    summary = response.choices[0].message.content
```

```bash
pxt schema update app.py my_app
```

Then `t = pxt.get_table('my_app.articles')` and `t.insert(...)`. Or [HTTP serving](/howto/deployment/serving). Same file against `pxt://org:db`: [Deploy to Pixeltable Cloud](/howto/deployment/cloud).
