## Schema

An <Tooltip tip="You insert this value. It is stored.">annotation</Tooltip> is a stored column. An <Tooltip tip="Pixeltable computes this on insert. You assign an expression.">assignment</Tooltip> is a computed column. Use `pxt.Column(...)` when you need `primary_key` or `stored=False`. A bare `doc_id: pxt.Int` is required; it is not a primary key.

```python app.py
import pixeltable as pxt
import pixeltable.functions as pxtf

TableModel = pxt.model_base()


@pxt.udf
def excerpt(text: str, n: int = 12) -> str:
    return text if len(text) <= n else f'{text[:n]}...'


class Docs(TableModel, name='docs'):
    doc_id = pxt.Column(type=pxt.Int, primary_key=True)
    title: pxt.String
    body: pxt.String | None
    published: pxt.Bool
    title_upper = pxtf.string.upper(title)
    summary = excerpt(title)
    unstored = pxt.Column(
        value=pxtf.string.lower(title), stored=False
    )
    __indexes__ = [
        pxt.EmbeddingIndex(
            body, embedding=embed_fn, name='body_idx'
        )
    ]


class Published(
    TableModel, name='published', base=Docs.where(Docs.published)
):
    headline = Docs.title_upper + '!'


class Titles(
    TableModel,
    name='titles',
    base=Docs.select(Docs.doc_id, t=Docs.title),
):
    shouted = t + '!'  # t is the select() alias
```

`base=Docs.where(...)` inherits columns. `base=Docs.select(...)` projects. Details: [Views](/platform/views).

A `@pxt.udf` defined in this file is recorded by file path. Renaming the file leaves columns that call it unable to compute. Hosted runtime packaging: [Cloud](/howto/deployment/cloud#hosted-catalog).

<CodeGroup>

```bash check
pxt schema check app.py
```

```bash diff
pxt schema diff app.py my_app
```

```bash update
pxt schema update app.py my_app
```

```bash prune

```

</CodeGroup>

## Services

The same file declares a `FastAPIRouter`:

```python app.py
ingest = FastAPIRouter(name='ingest')
ingest.add_insert_route(
    Docs,
    path='/docs',
    inputs=[Docs.doc_id, Docs.title, Docs.published],
    outputs=[Docs.title_upper],
)
```

Apply order: [Quickstart](/overview/quick-start). Hosted HTTP: [Cloud](/howto/deployment/cloud).

<AccordionGroup>
  <Accordion title="Insert" icon="plus" detail="Every required column. Nullable columns may be omitted.">
    The row is stored. Computed columns run. The response is `outputs`.
  </Accordion>
  <Accordion title="Compute" icon="calculator" detail="Same inputs as insert. The row is not stored.">
    Preview or dry-run. Identical to insert except nothing is written.
  </Accordion>
  <Accordion title="Update" icon="pen" detail="Columns to change. Primary key is in the request, not in inputs=.">
    Recomputes dependent columns on the matched row.
  </Accordion>
  <Accordion title="Delete" icon="trash" detail="Defaults to the primary key. The key is in the request.">
    `match_columns` deletes by a non-key column instead.
  </Accordion>
</AccordionGroup>

Uploads, background jobs, query routes, and `include_router`: [HTTP serving](/howto/deployment/serving).

After you edit the file:

<Steps>
  <Step title="Check and diff" icon="magnifying-glass">
    ```bash
    pxt schema check app.py
    pxt schema diff app.py my_app
    ```
  </Step>
  <Step title="Apply schema" icon="table">
    ```bash
    pxt schema update app.py my_app
    ```
  </Step>
  <Step title="Restart the service" icon="globe">
    ```bash
    pxt service update app.py my_app
    pxt service list
    ```
  </Step>
</Steps>

<Warning>
  A schema change with a service already running returns **409** until restart, even when `pxt service diff` is in sync. Apply schema, then `pxt service stop ingest` and `pxt service update`. Route-only edits: `pxt service update` restarts what changed.
</Warning>

The port is assigned. Do not hard-code `:8000`. Inspect with `pxt dashboard`, `pxt ls`, and `pxt errors`.

## For agents

<Prompt description="Emit the application file. Run diff. Read the exit code. Apply." icon="robot" actions={["copy", "cursor"]}>
Emit a Pixeltable application file (`app.py`) with `TableModel` classes and `FastAPIRouter` routes. Run `pxt schema diff app.py TARGET`. Exit 0 means in sync. Exit 2 means pending; `--json` is the plan. Exit 1 is an error that names the file, declaration, or key. Then `pxt schema update`. Do not emit an ordered list of `create_table` / `add_computed_column` calls. Destructive ops need `--allow-destructive`.
</Prompt>
