The [Pixeltable Starter Kit](https://github.com/pixeltable/pixeltable-starter-kit) is the example home: serving, batch, and FastAPI + React patterns, plus `uvx pixeltable-new` templates.

```bash
uvx pixeltable-new --list
uvx pixeltable-new myapp --template knowledge-base
```

First-run without a template: [Quickstart](/overview/quick-start) (`pxt service example` → `pxt schema update` → `pxt service update`).
